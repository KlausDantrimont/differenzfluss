# 06 – Empörung verlangsamen

## Worum es geht

Empörung ist ein starkes Signal.

Sie sagt:

> Da stimmt etwas nicht.

Das kann wichtig sein.

Empörung kann auf Unrecht, Gewalt, Lüge, Demütigung oder Grenzverletzung hinweisen.

Aber Empörung kann auch gesteuert werden.

Dann wird sie zur Fernbedienung.

KI kann helfen, Empörung zu verlangsamen.

Nicht, um sie wegzumachen.

Sondern, um sie prüfbar zu machen.

---

## Grundprompt

```text
Arbeite mit dem Denkzeug-Modell.

Analysiere diesen empörenden Text, Clip, Screenshot oder Post.

Material:
[Text oder Beschreibung einfügen]

Bitte beantworte:

1. Welche Gefühle soll das Material vermutlich auslösen?
2. Welche Sofort-Handlung wird nahegelegt?
3. Welche Wörter oder Bilder verstärken Empörung?
4. Welche Informationen fehlen möglicherweise?
5. Wird eine konkrete Handlung kritisiert oder eine Person/Gruppe markiert?
6. Wird aus einem Einzelfall auf eine ganze Gruppe geschlossen?
7. Welche Deutung wird nahegelegt?
8. Welche alternativen Deutungen wären möglich?
9. Welche Fragen müsste man stellen, bevor man urteilt?
10. Formuliere eine langsamere, prüfendere Version.

Wichtig:
- Lösche die Empörung nicht.
- Prüfe ihre Bauweise.
- Unterstelle keine sichere Absicht.
- Unterscheide Wirkung und Wahrheit.
- Ziel ist mehr Spielraum.
````

## Beispielprompt 1: Teilungsdruck

```text
Arbeite mit dem Denkzeug-Modell.

Analysiere diesen empörenden Text.

Material:
„Unfassbar, was der gemacht hat. Teilt das, damit alle sehen, wie der drauf ist.“

Bitte beantworte:

1. Welche Gefühle soll das Material vermutlich auslösen?
2. Welche Sofort-Handlung wird nahegelegt?
3. Welche Wörter oder Bilder verstärken Empörung?
4. Welche Informationen fehlen möglicherweise?
5. Wird eine konkrete Handlung kritisiert oder eine Person/Gruppe markiert?
6. Wird aus einem Einzelfall auf eine ganze Gruppe geschlossen?
7. Welche Deutung wird nahegelegt?
8. Welche alternativen Deutungen wären möglich?
9. Welche Fragen müsste man stellen, bevor man urteilt?
10. Formuliere eine langsamere, prüfendere Version.
```

---

## Erwartete gute Antwort

```text
1. Ausgelöste Gefühle:
Empörung, Wut, Ablehnung, Dringlichkeit.

2. Sofort-Handlung:
Teilen.

3. Empörungsverstärker:
„Unfassbar“, „wie der drauf ist“, Aufforderung zum Teilen.

4. Fehlende Informationen:
Was genau passiert ist, was vorher war, ob es Kontext gibt, ob ein Clip vollständig ist.

5. Markierung:
Die Person wird als Ganzes negativ markiert.

6. Gruppenschluss:
Im Satz selbst nicht zwingend, aber die Formulierung kann zur Feindmarkierung führen.

7. Nahegelegte Deutung:
Die Person hat etwas eindeutig Schlimmes getan und soll öffentlich sichtbar gemacht werden.

8. Alternative Deutungen:
Es könnte Kontext fehlen. Es könnte ein Ausschnitt sein. Es könnte eine Missdeutung sein. Es könnte trotzdem ein reales Problem zeigen.

9. Prüffragen:
Was genau ist passiert? Gibt es Kontext? Ist das Material vollständig? Wer hat es geteilt? Warum soll es sofort geteilt werden?

10. Langsamere Version:
„Das wirkt auf den ersten Blick problematisch. Bevor man es teilt oder bewertet, müsste man wissen, was genau passiert ist und ob Kontext fehlt.“
```

```text
4. Wenn man wartet:
Man kann prüfen, ob das Material echt, vollständig und fair geteilt ist.

5. Ruhigere Handlung:
Nicht sofort teilen. Erst Quelle, Kontext und mögliche Folgen prüfen.
```

### Mögliche gute Ausgabe


## Prompt: Markierung von Personen oder Gruppen prüfen

```text
Arbeite mit dem Denkzeug-Modell.

3. Wird aus einer Handlung eine Identität gemacht?
4. Wird aus einem Fall auf viele geschlossen?
5. Welche genauere Formulierung wäre möglich?
```

### Beispiel

```text
Arbeite mit dem Denkzeug-Modell.

Prüfe, ob dieser empörende Text eine konkrete Handlung kritisiert oder eine Person/Gruppe markiert.

Text:
„Typisch diese Leute. Immer dasselbe. Komplett gestört.“

Bitte beantworte:
1. Welche konkrete Handlung wird genannt?
2. Welche Person oder Gruppe wird markiert?
3. Wird aus einer Handlung eine Identität gemacht?
4. Wird aus einem Fall auf viele geschlossen?
5. Welche genauere Formulierung wäre möglich?
```

### Mögliche gute Ausgabe

```text
1. Konkrete Handlung:
Keine konkrete Handlung wird genannt.

2. Markierung:
„diese Leute“ und „komplett gestört“ markieren eine Gruppe oder Person.

3. Identität:
Ja. Es wird nicht Verhalten beschrieben, sondern abgewertet.

4. Verallgemeinerung:
Ja. „typisch“ und „immer“ machen aus einem Fall ein Muster.

5. Genauere Formulierung:
„Ich möchte wissen, welche konkrete Handlung gemeint ist und ob sie wirklich für eine größere Gruppe steht.“
```


## Qualitätsprüfung

Eine gute KI-Antwort in diesem Bereich:

```text
nimmt Empörung ernst
verlangsamt Sofortdruck
sucht fehlenden Kontext
trennt Beobachtung und Deutung
erkennt Empörungswörter
prüft Markierung und Verallgemeinerung
liefert faire Fragen
formuliert eine langsamere Version
```

Eine schlechte KI-Antwort:

```text
redet Empörung pauschal klein
verstärkt Empörung ungeprüft
fordert sofortige Handlung
übernimmt Markierungen
verallgemeinert auf Gruppen
unterstellt sichere Absicht
ignoriert fehlenden Kontext
macht den Raum enger
```

## Leitsatz

> Empörung kann eine Alarmanlage sein.
> Aber auch eine Fernbedienung.
> KI soll helfen, den Unterschied prüfbar zu machen.
