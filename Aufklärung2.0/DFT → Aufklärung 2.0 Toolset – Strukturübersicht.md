## 2. Übersicht als Tabelle

| **Kategorie**      | **Tool**                | **Beschreibung**                                               | **Einsatzbereich**                 |
|--------------------|------------------------|-----------------------------------------------------------------|-------------------------------------|
| **Erkennen**       | Framing-Analyzer       | Erkennung von Framing, Auslassungen, Narrativ-Mustern          | Medien, Bildung                     |
|                    | Narrativ-Mapper        | Visualisierung von Narrativ-Netzwerken                         | Medienkompetenz, Politiktransparenz |
| **Reflektieren**   | Meta-Kommentarmodul    | Metainformationen zu Inhalten (Prämissen, Quellen, Auslassung) | Kultur, Medien, Debatten            |
|                    | Diskurs-Assistent      | Sichtbarmachung von Positionen, Annahmen in Debatten           | Politik, Bürgerforen                |
| **Kooperieren**    | Feedback-Knoten        | Periodische Überprüfung politischer/organisatorischer Prozesse | Politik, Verwaltung                  |
|                    | Mikro-Governance-Kits  | Dezentrale Entscheidungswerkzeuge                              | Gemeinden, NGOs                     |
| **Transformieren** | DFT-Impact-Simulator   | Simulation von Effekten (Politik, Bildung, Medien)             | Think Tanks, Parlamente             |
|                    | Resonanz-Monitor       | Echtzeitmessung von Resonanzen in Diskursen                    | Krisenkommunikation, Forschung      |

---

## 3. Legende
- **Erkennen** = Wahrnehmen und Sichtbarmachen von Strukturen.  
- **Reflektieren** = Kontextualisieren, Selbstbezüglichkeit offenlegen.  
- **Kooperieren** = Resiliente Netzwerke etablieren.  
- **Transformieren** = Dynamische Anpassung der Systeme.
