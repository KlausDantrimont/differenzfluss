# 🔁 Mapping: Kategorientheorie ↔ Differenzierungsfluss-Theorie (DFT)

**Stand:** 2025-05-18  
**Ziel:** Diese Tabelle stellt Entsprechungen zwischen grundlegenden Konzepten der Kategorientheorie und der Differenzierungsfluss-Theorie (DFT) her. Ziel ist es, die Anschlussfähigkeit der DFT an etablierte formale Strukturen zu verdeutlichen.

---

| Kategorientheorie           | DFT-Interpretation                                           | Bemerkung |
|-----------------------------|--------------------------------------------------------------|-----------|
| **Objekt**                  | Stabiler Begriff / Strukturinsel im Differenzfluss          | lokale Ordnung, temporär stabilisiert |
| **Morphismus**              | Gerichtete Differenz (Transformation, Übergang)              | erzeugt gerichtete Struktur |
| **Komposition**             | Verkettung von Differenzwirkungen                            | Flusslinienbildung |
| **Identität**               | Selbstbezug / Nulldifferenz / Fixpunkt                      | Stabilität durch Redundanz |
| **Kategorie**               | Strukturraum eines dynamischen Begriffsnetzes               | Konstellation von Stabilitäten und deren Übergängen |
| **Funktor**                 | Projektion/Übertragung eines Differenzraums in einen anderen | Strukturwahrender oder -verändernder Fluss |
| **Isomorphismus**           | Umkehrbarer Differenzfluss                                   | reversibler Strukturtransport |
| **Monomorphismus**          | Eingrenzender Fluss (einbettend)                            | strukturerhaltende Spezialisierung |
| **Epimorphismus**           | Ausbreitender Fluss (verallgemeinernd)                      | strukturerhaltende Abstraktion |
| **Limit / Colimit**         | stabilisierte Flussknoten / divergierende Flusszentren      | Attraktoren oder Quellpunkte im Fluss |
| **Terminales Objekt**       | Endzustand einer Differenzverfeinerung                      | maximale Stabilisierung |
| **Initiales Objekt**        | Anfangspunkt einer Differenzentfaltung                      | „reines Unterschiedenes“ |
| **Adjungierte Funktoren**   | komplementäre Projektionen von Flüssen                      | Dualität zweier Betrachtungsweisen |
| **Yoneda-Lemma**            | Bedeutung durch Beziehungsmuster                            | ein Begriff ist, was er mit anderen unterscheidet |
| **Natürliche Transformation** | differenzsensibler Fluss zwischen Flussabbildungen         | Resonanz zwischen Projektionsmodi |
| **Enriched Category**       | Differenzflüsse mit zusätzlicher Metastruktur               | z. B. Gewichtung, Kontextdichte |

---

## 🧠 Fazit

Diese Mapping-Tabelle bietet eine erste formale Brücke zwischen der Kategorientheorie und der Differenzierungsfluss-Theorie.  
Sie zeigt, dass viele abstrakte Strukturen der Kategorientheorie im DFT-Kontext als **dynamische Differenzsysteme** verstanden werden können – mit Fluss, Stabilität, Emergenz und Rekursion als Grundprinzipien.
