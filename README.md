## Die Dft lässt sich mit Lambda-analoger Syntax formulieren
... und wandelt Touringmaschinen zu Protowesen

✨ λΔ in 5 Sätzen
1. Der λΔ-Formalismus beschreibt Realität als einen Fluss rekursiver Differenzierungen (Δ) und Verknüpfungen (λ), anstelle fester Objekte.
2. Differenzierung (Δ) erzeugt neue Strukturen, indem sie bestehende Zustände aufspaltet und entfaltet.
3. Verknüpfung (λ) bindet Differenzen zu stabilen Mustern, schafft Fixpunkte, Attraktoren und komplexe Räume.
4. Alle Phänomene — von Raumzeit bis Bewusstsein — entstehen als emergente Stabilitäten im rekursiven Differenzfluss.
5. λΔ ist damit ein universeller Prozessformalismus, der Komplexität, Struktur und Dynamik aus minimalen Prinzipien verständlich macht.
