**Hexwars – ein kleines Strategiespiel!** ⬡

Vier Parteien, ein Spielfeld, jede Menge Konfliktpotenzial.

Ein rundenbasiertes Strategiespiel, bei dem man gegen drei KI-Gegner antritt. Die versuchen, einem das Leben möglichst schwer zu machen.

Entstanden ist das Ganze aus Neugier auf Spielmechanik, künstliche Intelligenz und die Frage, wie man einer Maschine taktisches Verhalten beibringt.

Jetzt darf gespielt werden. Kostenlos, direkt im Browser, ohne Anmeldung.

🎮 https://klausdantrimont.github.io/differenzfluss/hexwars/

Feedback, Kritik und Erfolgsmeldungen sind willkommen. Besonders interessiert mich natürlich, ob jemand die KI für zu schlau hält. ;-)
